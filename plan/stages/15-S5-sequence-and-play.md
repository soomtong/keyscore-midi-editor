# S5 — Sequence 모드(리듬형 녹음)와 Play 모드

목표: 미리 적은 음높이 열에 박자를 입혀 녹음하고, 건반 시뮬레이션으로 음색을 확인한다. M2·M3 게이트에 해당한다.

관련 REQ: 5.2, 5.4, 5.11(Sequence·Play), 8.1 NF-5, 9.3, 2절의 Sequence 관련 결정(미리 적기·불일치·테이크 undo·자동 퀀타이즈·판정 임계값·메트로놈)
선행: S4, SP-1

## Task 목록

### S5-T1 Sequence 레인 뷰

- 범위: 흐르는 박자 그리드(모노토닉 클록 보간), 카운트인 표시, 판정 색·모양 표시(Perfect/Good/Early/Late), 시각 메트로놈(테두리 깜빡임, 상태줄), 상태줄 `n/m`.
- 테스트 게이트: 가짜 클록으로 그리드 위치가 틱과 일치.

### S5-T2 키 이벤트 타임스탬프와 레이턴시 보정

- 범위: REQ 9.3·NF-5. 보정 마법사(10번 탭 평균, 설정 > 입력), 사용자별 값 하나.
- 결정 분기: SP-1 결과에 따라 (A) GPUI가 넘기는 타임스탬프 사용, (B) `NSEvent.addLocalMonitorForEvents`로 받은 타임스탬프를 핸들러와 짝짓기, (C) 수신 즉시 `mach_absolute_time`.
- 테스트 게이트: 합성 키 이벤트(알려진 타임스탬프)로 분해능 ≤ 1 ms 확인. 보정값 적용 전후 판정 변화 테스트.
- 리뷰 초점: 메인 스레드 프레임 지연이 타임스탬프에 섞이는 경로가 남았는가.

### S5-T3 녹음 엔진

- 범위: `Cmd+R` 진입, 카운트인(메트로놈 강제 켬), 미리 적기(열 = 같은 클립의 Step 노트, 화음 한 항목, 타격 초과 무시·부족 시 원래 자리 유지, 열 끝 자동 정지), 직접 치기, 루프 녹음(겹쳐/덮어), 테이크 = undo 한 단위, `Shift+Tab` 테이크 버리기, `Tab` 건너뛰기/테이크 확정, 테이크 종료 시 자동 퀀타이즈(기본 켬, 현재 길이 코드 그리드, 100%), 판정 임계값 3단계.
- 테스트 게이트: 합성 타이밍 열(±5/±30/±60 ms)로 판정 분포 확인. 열 12개에 타격 16개 → 12개만 반영. 열 16개에 타격 12개 → 4개 원래 자리. 테이크 undo 한 번에 전체 복원. 자동 퀀타이즈 끔 설정 반영.
- 리뷰 초점: 녹음 중 모델 변경이 스케줄러 스냅샷과 충돌하지 않는가(재생 중 편집 TRN-3 경로).

- 이월(S2-T3, 결정 `docs/decisions/2026-10-17-keymap-conflicts.md` A13): Sequence의 `Esc`(`mode::Normal`)는 녹음을 멈추고 테이크를 남긴다(자동 퀀타이즈 적용, REQ 5.2). 카운트인 중이면 그냥 Normal. Play의 `Esc`는 눌린 노트의 Note Off를 보낸 뒤 Normal로 간다.
- 이월(결정 `docs/decisions/2026-10-17-keymap-conflicts.md`, 2026-10-24): A4 루프 녹음이 켜져 있으면 `Sequence > Loop`의 `tab`/`shift-tab`(테이크 확정·버리기)이 미리 적기의 건너뛰기·되감기보다 이긴다(컨텍스트 깊이). `default.json`의 A4 자리 둘을 채우고 REQ 5.11에 우선순위 문장을 넣는다. B24 Play의 서스테인은 수식키 변경 이벤트로 `play::Sustain`을 켜고 끄며 키맵에 두지 않는다. 키맵 편집기에는 「고정 키」로 보인다.

### S5-T4 Play 모드

- 범위: REQ 5.4. `Cmd+K`, 건반 뷰 「연주」 버튼, 트랙 출력 전환(`Tab`, `F1`–`F8`, 클릭), `,`/`.` 프로그램 체인지, 서스테인 `Shift`(CC64), 옥타브, 드럼 트랙 라벨 모드(5.13: 라벨 키, `[` `]` 킷 페이지).
- 테스트 게이트: 키 다운·업이 Note On/Off 쌍으로 루프백에 도착, 키 반복(auto-repeat) 이벤트가 중복 Note On을 내지 않음.
- 이월(S3-T5): 건반 뷰(`keyboard_view.rs`, `keyboard_view_window.rs`)는 Step에서만 그린다. Play에서도 하단 영역에 그리고, 옥타브 버튼은 `play::OctaveDown`·`play::OctaveUp`을 내며, 「연주」 버튼을 더한다. 라벨 규칙은 `docs/reports/s3-t5/plan.md` 「끝의 정의」 2·3.
