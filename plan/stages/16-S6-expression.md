# S6 — 표현: 컨트롤러 레인, 가사, 드럼

목표: 벨로시티·CC·벤드를 마우스로 그리고, 노트에 가사를 붙이며, 드럼 트랙이 GM 라벨로 동작한다.

관련 REQ: 5.9, 5.13, 5.15, 6.7, LYR-1~6, KM-7 예외
선행: S5

## Task 목록

### S6-T1 컨트롤러 레인 Element

- 범위: CTL-1·2·3·4·9. `c`/접기 화살표, 높이 드래그, 피아노롤과 가로 동기, 벨로시티 막대, CC 레인(번호 추가 드롭다운), 벤드 레인(중앙 0, ±8192), `Tab` 레인 전환, Controller 모드(`Shift+c`, 세로로 여러 레인).
- 테스트 게이트: 벤치(포인트 10,000). 스크롤 동기 UI 테스트.
- 이월(S1-T3 리뷰 1 제안 3, 리뷰 2 지적 1): CTL-4 벤드 레인은 「가운데 0, ±8192」이고, 인코더 `pitch_bend`는 32비트 부호 없는 값(가운데 0x8000_0000)을 받는다. 레인 값과 모델 32비트 값 사이의 변환, 14비트로 표현할 수 없는 +8192(최대 +8191) 처리를 이 Task에서 정한다. S6-T2(즉시 송신)와 S6-T3(샘플링 송신)은 이 결정을 따른다.

### S6-T2 커브 드래그 편집

- 범위: 펜·직선(`Shift`)·곡선(`Alt`)·포인트 추가·삭제·영역 비례·휠 미세, 벨로시티 막대 드래그, 드래그 한 번 = undo 하나(CTL-8), 그리는 동안 즉시 송신(CTL-5, 정지 중에도).
- 테스트 게이트: 마우스 시뮬레이션 — 직선 드래그가 두 포인트만 만든다, 펜 드래그의 포인트 수가 이동 거리에 비례하고 중복 틱이 없다. 드래그 중 루프백에 CC가 도착.

### S6-T3 CC 송신 샘플링과 클립 결합

- 범위: CTL-6(5 ms 샘플링, 값 같으면 생략, 재생 시작 chase), CTL-7(레인 데이터가 클립에 속함, 이동·복제·분할 시 경계 보간), 기본값(트랙 기본 벨로시티).
- 테스트 게이트: 스케줄러 루프백 — 램프 1초가 ≤ 200개 CC로 송신되고 단조 증가. 클립 분할 후 양쪽 경계 값이 분할 시점 보간값과 같음.
- 리뷰 초점: 샘플링이 스케줄러 스레드에서 할당 없이 되는가(포인트 열은 스냅샷에 미리 계산).
- 이월(S1-T6): SMF의 CC·벤드·채널 프레셔는 `keyscore_midi::Song`의 트랙별 32비트 포인트 열까지만 보존한다(CTL-10). 모델에 레인 저장소가 생기면 `Song::to_project`·`from_project`가 레인을 클립으로 옮기게 하고, 「SMF → 모델 → SMF」에서 CC가 보존되는 테스트를 더한다.

### S6-T4 드럼 트랙

- 범위: REQ 5.13. 채널 10 자동 드럼 트랙, 라벨 표(설정에서 추가·수정), Step 모드 라벨 키 매핑·킷 페이지, 건반 뷰 라벨, 피아노롤 행 라벨(음이름 대신), SMF 가져오기에서 채널 10 자동 판별, 텍스트 문법 연동(S0-T5 완료분 사용).
- 테스트 게이트: 드럼 트랙에서 `A`가 노트 36. 비GM 라벨을 추가해 저장·복원.

### S6-T5 가사 모드

- 범위: LYR-3·4·5. `w` 진입, IME 문자 입력(KM-7 예외), `Space`/`Tab`/`Shift+Tab`/`-`/`Backspace`/`Esc`, 상태줄 `LYRIC n/m`, 첫 진입 안내 한 줄, 한 줄 붙여넣기 분배(ko·ja 글자, en 하이픈·공백), 피아노롤·배치 뷰 표시(줌에 따라 숨김, 멜리스마 밑줄), undo 노트 하나 단위.
- 테스트 게이트: 한글 조합 중 입력(자모 단계)이 노트에 반영되지 않고 확정 음절만 붙음(IME 시뮬레이션). 영어 `lov-ing you` 분배 결과. 음절이 남으면 경고.
- 리뷰 초점: 가사 모드에서 물리 키 매칭이 완전히 꺼지는가(`h`가 이동이 아니라 글자).
