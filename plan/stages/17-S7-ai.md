# S7 — AI: 생성, 어시스트, 가사 도우미, 프롬프트 실험실

목표: OpenRouter를 통해 소형 LLM이 계이름 텍스트로 클립을 만들고, Step 입력 중 다음 프레이즈를 제안하며, 실험실에서 템플릿·모델을 비교한다.

관련 REQ: 5.12, 6.8 AI-1~24, LYR-7·8, 13절(벤치마크), 2절 AI 관련 결정(OpenRouter 키만, 템플릿 영어, 트리거, 2 s 폐기)
선행: S6, SP-5, SP-6

## Task 목록

### S7-T1 API 클라이언트와 키 저장

- 범위: AI-1·10. OpenAI 호환 Chat Completions(스트리밍), 베이스 URL·모델·키 설정, 키체인 저장(`security-framework`), 타임아웃 30 s·취소, 백그라운드 스레드, 네트워크 없음 상태 보고. 어시스트용·생성용 모델 두 자리(AI-19).
- 테스트 게이트: 로컬 모의 서버(wiremock)로 스트리밍·타임아웃·401·429 처리. 키가 설정 파일·로그에 평문으로 남지 않음(grep 테스트).
- 리뷰 초점: 응답 본문·키가 로그·에러 메시지에 새는 경로.

### S7-T2 템플릿 시스템

- 범위: AI-14·15·22. 네 층 조립(시스템·과제·컨텍스트·사용자), `assets/prompts/*.md`와 사용자 폴더, `{{bars}}` 등 변수 치환, 핫리로드, 사용자 복사·수정·되돌리기, 취향 지시, few-shot 예시 포함, 드럼 라벨 표·대괄호 문법 포함(AI-3·AI-13), 영어 템플릿 + 「요청은 한국어일 수 있다」.
- 테스트 게이트: 조립 결과 insta 스냅샷(생성 종류별 × 드럼/멜로디). 토큰 상한 초과 시 컨텍스트 범위 축소 순서가 결정적.
- 이월(S0-T5 리뷰 1 제안 5): REQ 5.13은 AI가 모르는 드럼 라벨을 내면 「그 타격만 건너뛴다」, 결정 Q6(`docs/decisions/2026-10-11-ktext-grammar-ambiguities.md`)은 AI 응답을 엄격 모드로 읽어 오류로 처리한다. 착수 전에 결정 요청으로 정한다.

### S7-T3 컨텍스트 조립과 응답 파싱

- 범위: AI-3·4·6·7·23. 템포·박자·조성·트랙 프로그램·선택 범위/앞뒤 4마디·다른 트랙·참조 클립을 계이름 텍스트로, 스트리밍 점진 파싱(S0-T5 파서의 증분 모드), 고스트 클립 생성, 파싱 실패 시 오류 첨부 재요청 1회, `@track` 멀티트랙 → 트랙 매칭·생성, 음역 접기·그리드 맞춤.
- 테스트 게이트: 모의 서버 응답(정상·부분 깨짐·완전 깨짐·멀티트랙)에 대한 테이블 테스트. 재요청이 정확히 1회.
- 리뷰 초점: 고스트가 모델(undo 히스토리)에 들어가지 않는가 — 수락 전에는 별도 상태.

### S7-T4 AI 패널과 생성 흐름

- 범위: AI-2·5·8·20·21. `a` 패널(인스펙터 탭), 구조화 필드(역할·마디 수·음역·밀도·분위기), 한 줄 프롬프트, 생성 종류(5.12 표 전부, 보컬 포함 LYR-7), 전송 내용 보기·응답 원문, `Tab` 수락(undo 하나)·`Esc`·`r`·`e`·`Enter`, 후속 지시(대화 유지, `Shift+Tab` 이력), 결정적 편집 분류(AI-8).
- 테스트 게이트: 모의 서버로 전체 흐름 UI 테스트. 수락 전 `Cmd+Z`가 고스트를 건드리지 않음. 후속 지시 요청에 직전 요청·응답이 포함됨(스냅샷).

- 이월(S2-T3, 결정 `docs/decisions/2026-10-17-keymap-conflicts.md` A13): 요청 중에는 컨텍스트 `AI > Requesting`을 두고 `escape` → `ai::CancelRequest`(신규, 요청만 취소, 패널 유지, AI-10). 그 밖의 `AI` 컨텍스트 `escape`는 `ai::Dismiss`(결과 버리고 패널 닫고 Normal).
- 이월(결정 `docs/decisions/2026-10-17-keymap-conflicts.md`, 2026-10-24): A7 컨텍스트 `AI > Prompt`(입력 중, `enter`=전송)와 `AI > Preview`(결과 보는 중, `r` 재생성·`e` 프롬프트 수정·`enter` 다시 듣기)를 두고 `tab`/`escape`로 오간다. A10 vim `g i`=AI 패널. A12 팔레트 `:ai` 접두. `default.json`의 A7 자리를 채우고 REQ 5.12·AI-5 문구를 고친다.

### S7-T5 어시스트

- 범위: AI-11·12·13. `AI✦` 토글, 마디 완료·유휴(설정 0.5–5 s) 트리거, 백그라운드 요청·커서 이동 시 폐기·2 s 초과 폐기(SP-6 결과로 조정), 300 토큰 상한, 컨텍스트 캐시, 고스트 노트와 `Tab ↵` 힌트, `Tab` 마디 단위 수락·`Esc` 고스트만 제거·계속 치면 사라짐, 깜빡이는 토글.
- 테스트 게이트: 가짜 클록·모의 서버 — 유휴 1.5 s에 요청 1회, 타이핑 중 요청 없음, 커서 이동 후 도착한 응답 무시, 2.1 s 응답 폐기. 연속 `Tab` 두 번이 두 마디.
- 리뷰 초점: 요청이 메인 스레드를 막는 경로. 캐시 키에 커서 위치·트랙이 들어가는가.

### S7-T6 가사 도우미

- 범위: LYR-7(어시스트가 가사 트랙에서 가사+음 제안), LYR-8(가사 모드에서 `a`로 가사만 제안, 고스트 글자, `Tab` 수락).

### S7-T7 프롬프트 실험실

- 범위: AI-16·17·18·24. 패널 「실험실」 탭, 픽스처(번들 8곡 + 프로젝트 범위 저장) × 템플릿 버전 × 모델 격자 실행, 응답 원문·고스트·자동 점수(파싱·마디 수·음역 위반·조성 밖·밀도 편차·연속성·노트당 음절)·지연·토큰·비용, 듣기 비교·별표, `prompts/lab/<날짜>.json` 저장, 「이 모델을 기본으로」 적용, MIDI Agent 예시 프롬프트 4문장 픽스처.
