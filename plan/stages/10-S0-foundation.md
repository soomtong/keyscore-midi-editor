# S0 — 기반: 워크스페이스, 모델, 텍스트 문법

목표: UI 없이도 곡을 표현하고, 저장하고, 텍스트로 왕복할 수 있는 순수 Rust 기반을 만든다. 이 단계가 끝나면 `ksq-cli`로 `.ksq ↔ 계이름 텍스트` 변환이 된다.

관련 REQ: 3, 5.6(길이 코드 표), 5.10(클립 규칙), 5.13, 5.14, 5.15(모델 부분), 6.1, 6.6 IO-1·IO-3, 9.5, 9.6
선행: 02-spikes 전부

## Task 목록

### S0-T1 워크스페이스와 CI 뼈대

- 범위: `Cargo.toml` 워크스페이스, 다섯 crate 빈 껍데기, `rust-toolchain.toml`, `deny.toml`, `LICENSE`(BSD-3-Clause), `NOTICE`, GitHub Actions(fmt·clippy·test·deny, macOS 러너).
- 테스트 게이트: CI가 초록. `cargo deny check` 통과.
- 리뷰 초점: 의존 방향이 `Cargo.toml`에서부터 지켜지는가(`core`가 아무것도 의존하지 않는가).

### S0-T2 핵심 모델 타입

- 범위: `Project`, `Track`(SEQ-7 속성 전부), `Clip`, `Note`(SEQ-3, `lyric: Option<String>` 포함), `CcPoint`, `Tick`(newtype, u64), `Key`(장·단조 12개 + None), 채널 newtype(1–16 검증).
- 불변식을 타입으로: `Track::insert_clip`은 겹치면 `Err`. `Clip::insert_note`는 클립 길이 밖이면 `Err`. 노트 시작은 클립 기준.
- 테스트 게이트: proptest — 임의의 삽입·이동·분할 수열 뒤에도 「겹침 없음」「노트는 클립 안」이 성립. 채널 0·17 생성 불가. 이 속성 테스트는 이후 모든 단계의 회귀 테스트로 남는다.
- 리뷰 초점: 공개 API만으로 불변식을 깨뜨릴 수 있는 경로. `pub` 필드가 있으면 차단.

### S0-T3 템포 맵과 틱↔시각 변환

- 범위: 템포 맵·박자표 맵(SEQ-5), `tick_to_seconds`, `seconds_to_tick`, 마디·박 위치 계산. PPQ 960 고정(SEQ-6). v1 UI는 하나씩만 쓰지만 모델은 변화 이벤트 열을 가진다.
- 테스트 게이트: 템포 변화 3개가 있는 맵에서 왕복 변환 오차 0 틱. 1시간(120 BPM, 3,456,000틱) 누적 변환이 부동소수 오차 없이 정수로 떨어지는 구간 검증(NF-4 준비). criterion 벤치 기준값 커밋.
- 리뷰 초점: 부동소수 누적. 변환은 정수·유리수 산술로.

### S0-T4 undo 엔진

- 범위: 명령 패턴 undo/redo(EDT-1). 단위는 편집 동작 하나. 연속 같은 조작 묶기(coalesce) API. 무제한 히스토리(메모리 상한 설정).
- 테스트 게이트: 임의 편집 수열 N개 → undo N번 = 초기 상태(proptest). redo 후 새 편집이 redo 스택을 비움. coalesce 묶음이 한 번에 풀림.
- 리뷰 초점: undo가 불변식을 거쳐 가는가(undo로 겹침이 생길 수 없는가).
- 이월(S0-T2 리뷰): `Track`의 `PartialEq`는 `ClipId`를 비교한다. undo로 클립을 되살릴 때 원래 `ClipId`를 유지해야 「undo N번 = 초기 상태」가 성립한다(`docs/reports/s0-t2/report.md` 리뷰 대응 2 #5).

### S0-T5 계이름 텍스트 파서·내보내기

- 범위: REQ 5.14 전체 문법. `@track/@tempo/@time/@key`, 음·변화표·길이·점·타이·쉼표·`o`·`<`·`>`·`l`·`[ ]`·`n( )`·`|`·드럼 라벨(5.13 표)·`"가사"`·`~±틱` 접미·주석. 느슨한 가져오기(모르는 토큰 경고 후 건너뜀). 내보내기는 표의 토큰만.
- 테스트 게이트: proptest 왕복(임의 클립 → 내보내기 → 가져오기 = 원본, 가사 포함). insta 스냅샷(REQ 5.14 예시 블록). 오류 메시지에 줄·열. 드럼 라벨을 멜로디 트랙에 쓰면 오류. `c3`·`c12`는 오류.
- 결정 분기: SP-5가 문법 문제를 지적하면 결정 요청 후 보류.
- 리뷰 초점: 파서가 입력 크기에 선형인가(백트래킹 없음). 왕복이 「거의」 같은 곳(틱 반올림).

### S0-T6 `.ksq` 직렬화

- 범위: REQ 9.5·IO-1. JSON, 노트 `[Δt, d, p, v]` / `[Δt, d, p, v, "가사"]`, CC `[Δt, v]`, `format_version`, 모르는 키 보존(`serde_json::Value`로 보관 후 재기록), 없는 키 기본값. gzip 저장·읽기(`.ksqz`). 키 순서 고정, 2칸 들여쓰기, 노트 배열은 한 줄에 하나.
- 테스트 게이트: 왕복 동일(proptest). 모르는 키가 있는 파일을 열고 저장해도 그 키가 남는다. `format_version` 상위 버전 파일은 열되 경고. 10만 노트 파일 읽기 < 100 ms(벤치 기준 커밋).
- 리뷰 초점: 저장 중 크래시 시 원본 파일이 남는가(임시 파일 + rename).
- 이월(S0-T2 리뷰): `ClipId`는 저장하지 않고 읽을 때 새로 발급하며, 왕복 비교는 id를 뺀 내용으로 한다. 저장한다면 복원 때 전역 카운터를 `fetch_max`로 올리고 중복을 검증한다. 숨김 꼬리 노트(끝 > 클립 길이)도 왕복되어야 한다. 절대 피치 범위 결정(`docs/decisions/2026-10-12-absolute-pitch-range.md`)에 따라 읽기 쪽 거부 규칙을 정한다.

### S0-T7 퀀타이즈·조옮김·길이 스케일 연산

- 리뷰 초점: 연산이 클립 경계를 넘길 때(노트가 클립 밖으로) 처리 — 클립을 늘리는가, 거부하는가(REQ 5.10: 입력이 넘으면 클립이 늘어남).
