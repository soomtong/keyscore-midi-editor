# 적대적 리뷰: S2-T5a MIDI 엔진 연결과 트랜스포트 Action (리뷰 5회차, 좁은 확인)

근거: `docs/decisions/2026-10-17-s2-t5a-review-limit.md` A. 리뷰 4의 지적 1을 마지막 커밋(4855e5f)이 닫았는지와 같은 함수(`engine.rs` `prepare`)의 회귀만 본다. 리뷰 4 제안(공유 채널 트랙 삭제 후 재송신)은 S2-T5b 이월이라 범위 밖이다. 리뷰어는 구현자가 아니다.

## 확인한 것

- 순서: 들리지 않는 트랙의 뱅크·프로그램을 틱 0에 먼저 넣고, 그 뒤에 `render`를 전체 프로젝트에 한 번 부른다. 뱅크 CC와 프로그램은 `order_class`가 같은 1이고 `render`와 `Snapshot::new` 정렬이 모두 안정 정렬이라, 같은 틱·같은 포트·채널에서는 들리는 트랙이 들리지 않는 트랙 뒤에 오고 들리는 트랙끼리는 트랙 순서(뒤 트랙 승)다.
- 렌더 동등성: 전체 렌더 한 번은 `render`가 트랙 순서로 모은 뒤 정렬한 것이라, 이전의 트랙별 렌더를 이은 것과 노트·CC·프로그램이 같다. `render`는 들리는지 판정을 자체로 하고 `prepare`의 `audible` 클로저와 규칙이 같다(솔로가 있으면 솔로만, 뮤트+솔로는 솔로). 포트가 없는 트랙은 양쪽에서 빠진다.
- chase: 들리지 않는 트랙만 쓰는 채널의 프로그램은 틱 0 이벤트로 남아 재생 시작 때 나간다.
- 새 확인 테스트 `tests/review_s2_t5a_r5.rs` 6개 통과: 뒤 트랙 뮤트(앞 승), 앞 트랙 뮤트(뒤 승), 뒤 트랙 솔로(뒤 승), 둘 다 들림(뒤 승), 앞 트랙 뮤트+솔로(앞 승), 뮤트 전용 채널의 프로그램 chase와 그 트랙 노트 미송신.
- 지난 테스트 `engine` 8, `review_s2_t5a` 15, `_r2` 13, `_r3` 10, `_r4` 2 모두 통과. `cargo fmt --all -- --check`, `cargo clippy --workspace --all-targets -- -D warnings` 통과.
