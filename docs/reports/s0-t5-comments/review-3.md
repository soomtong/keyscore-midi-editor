리뷰 2 지적 1의 확인(A)
- 새 문장은 첫 `@track` 앞 `#`를 「두 모드 모두 오류, 가져오기 실패, 오류에 주석은 //」로 적는다. `run()`의 `self.voice.is_none()` 분기가 모드와 무관하게 `Err`를 내고 `c == '#'`이면 힌트를 붙이므로 일치한다.
- 트랙 안 설명(느슨 모드 한 글자 건너뜀 + 경고, 뒤의 글자는 토큰·음으로 읽힘, 음이름이면 음이 생김)은 `unknown()`의 `lenient` 호출과 일치한다. 「음이 생긴다」는 `a`–`g`가 있을 때라는 조건을 달고 있어 정확하다.
- 결정 Q1 개정(21–24행)과 「바뀐 동작」 표 두 행과 같은 내용이며 모순이 없다. 「아직 배포된 옛 파일은 없다」는 새 주장이지만 판정에 영향이 없다.
- 리뷰 대응 표 review-2 4행이 지적 1~4를 모두 다룬다. 3·4의 미반영 사유는 타당하다.

변경 범위(B)
- 테스트 파일 변경은 doc 주석뿐이다. `#[test]` 본문과 assertion은 그대로다. 코드 변경 없음.
