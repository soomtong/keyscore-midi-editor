# 적대적 리뷰: S0-T5 계이름 텍스트 파서·내보내기 (리뷰 6회차)

- 리뷰어 세션: 구현자(`s0t5-impl`)·리뷰 1–5회차와 다른 새 에이전트 세션. 결정 2026-10-13 개정(「선형 보장 + 상한 재기술」) 뒤의 확인 리뷰다.
- 대상 커밋: `b453709`(코드는 `33faf4c`)

## 1. 코드만 읽고 적은 「내가 검사할 것」

1. `33faf4c`가 주석과 리뷰 5 테스트의 기준만 바꿨는가(동작 불변, 입력 불변).
2. 「출력은 입력에 선형, 상수 256배 이내」를 넘는 입력. 예산(`voices`)은 시작까지의 온음표 쉼표만 센다. 쉼표 말고 성부마다 다시 쓰는 것(`@track` 줄, 옥타브 토큰, 60틱 미만 나머지 쉼표)은 세지 않는다.
3. 압축 입력의 다른 꼴(점·길이 생략, 화음, 드럼, 박자표, `~` 시작 보정)이 221배를 넘는가.
4. 예산을 우회해 새 성부를 강제로 여는 길(「모든 성부 커서가 한도보다 앞섬」)이 압축 입력과 더해지는가.
5. 엄격 모드로 읽히는 텍스트를 가져와 내보내면 다시 엄격 모드로 읽히는가(REQ 5.14 「그리드에 안 맞는 노트만 `~`」). 특히 `event`의 타이 사슬은 온음표보다 긴 노트만, `fill_gap`은 60틱 배수 쉼표만, `is_triplet`은 앞에서부터 탐욕이다.
6. 무작위 텍스트·클립에서 왕복, 재내보내기, 시작 보정 −480..+59, 패닉 없음.
