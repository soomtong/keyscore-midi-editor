# Task 계획: S2-T5b 트랜스포트 바와 트랙 목록

- 브랜치: `s2/t5b-transport-bar`(S2-T5를 나눈 둘째 Task)
- 관련 REQ: TRN-1, TRN-2, TRN-4, SEQ-7, SEQ-8, OUT-4, 7.1(화면 구성), 7.6(트랜스포트·트랙 목록 행), UI-11
- 선행 Task: S2-T5a(엔진·트랜스포트 Action), S2-T4(실행 함수, 명령 표)
- 이월 받음: 버튼은 `dispatch::run_action`(결정 C), `track::Next/Prev` 처리기를 탭 정지점보다 먼저(S2-T3 리뷰 1 제안 2), 공유 포트·채널 프로그램(S2-T5a 리뷰 1–5, 수용 테스트는 `docs/reports/s2-t5a/review-4.md` 부록)

## 끝의 정의 (내 말로)

1. 현재 트랙: 창이 「현재 트랙」(`TrackId`) 하나를 갖는다.
   - 새 프로젝트처럼 트랙이 없으면 없다.
   - 트랙이 지워지면 이웃 트랙으로 옮긴다.
   - 트랙 목록 클릭, `track::Next/Prev`(`Tab`/`Shift+Tab`, 5.11), `cursor::FirstTrack/LastTrack`으로 바꾼다.
   - 인스펙터(S2-T5c)와 트랜스포트 포트 드롭다운이 이 트랙을 다룬다.
2. 트랙 Action(편집은 각각 undo 한 단위)
   - `track::New`: 끝에 더한다. `NewAbove`·`NewBelow`는 현재 트랙 위·아래에 더한다.
     - 새 트랙은 기본 가상 포트에서 비어 있는 가장 낮은 채널을 받는다(SEQ-7).
     - 16채널이 다 차면 채널 1을 쓰고 「다른 포트를 권한다」 메시지를 남긴다(SEQ-8).
   - `Delete`(현재 트랙), `ToggleMute`, `ToggleSolo`, `MoveUp`, `MoveDown`, `SetChannel(n)`.
   - `edit::Undo`·`edit::Redo`: 문서 undo/redo. 텍스트 입력란 안의 undo(KM-14)는 입력란이 먼저 받는다.
   - 문서를 바꾸는 모든 처리기는 `cx.notify()`를 불러 재생 중 반영(TRN-3)을 지킨다.
3. 트랜스포트 바(7.1 상단, 왼쪽부터)
   - 재생(▶)·정지(■)·녹음(⏺, S5까지 꺼짐) 버튼.
   - 템포 필드(BPM, 소수 한 자리, Enter로 확정 → 틱 0의 `SetTempo`).
   - 박자표 필드(`4/4`, Enter → 틱 0의 `SetMeter`).
   - 조성 선택(없음 + 장·단조 24개 → `SetKey`).
   - 위치 표시 `마디.박.틱`(정지 때 처음 또는 일시정지 자리, 재생 중 갱신).
   - 메트로놈 토글(켜짐 표시), 탭 템포 버튼, `AI✦` 토글(S7까지 꺼짐).
   - 출력 포트 드롭다운: 현재 트랙의 포트를 보이고 바꾼다(가상 「KeyScore Out」 + OS 목적지). 트랙이 없으면 꺼진다.
   - TRN-4에 따라 템포·박자표·조성은 곡 전체에 하나다. 변화 편집 UI는 이후다.
   - 버튼은 모두 해당 Action을 실행 함수로 낸다. 필드 확정은 문서 편집이다.
   - 잘못된 입력(범위 밖 템포, `3/5` 같은 박자표)은 값을 바꾸지 않고 메시지를 남긴다.
   - `transport::SetTempo`(값 없으면 템포 필드에 포커스), `TapTempo`(마지막 탭들의 간격 평균, 2초 넘게 쉬면 새로 시작)를 처리한다.
4. 트랙 목록(7.1 왼쪽)
   - 줄마다 색, 이름, 「포트 · ch N」(채널 10은 「드럼」 표시, SEQ-7), M/S 토글 버튼.
   - 현재 트랙을 강조하고, 줄을 클릭하면 현재 트랙이 된다.
   - 아래에 `+`(트랙 추가) 버튼이 있다.
   - SEQ-8 경고: 같은 포트·채널을 둘 이상의 트랙이 쓰는데 프로그램이 다르면 그 줄들에 경고 표시를 둔다(접근성 레이블에 이유).
   - 탭 정지점은 두지 않는다. `Tab`은 트랙 이동이다.
5. 공유 포트·채널의 프로그램(S2-T5a 이월)
   - 재생 중 송신 비교를 트랙별에서 (목적지, 채널)별 「실효 음색」으로 바꾼다. 실효 음색은 chase와 같은 규칙이다: 들리지 않는 트랙 먼저, 들리는 트랙은 트랙 순서, 뱅크와 프로그램은 각각 마지막 값.
   - 실효 음색이 바뀌면(뮤트·솔로 변경, 공유 트랙 삭제, 프로그램 편집) 그 채널의 뱅크(있으면)와 프로그램을 보낸다.

## 불변식

- 버튼은 실행 함수를 거친다. 필드 확정과 트랙 편집은 문서 편집이고 undo 단위다.
- 현재 트랙은 늘 문서에 있는 트랙이거나 없음이다.

## 범위 밖

- 인스펙터·상태줄·포트 감시(S2-T5c), 트랙 이름·색 편집(인스펙터, S2-T5c)
- 루프 구간, 마디·박 이동 입력(`transport::GoTo`, S3), 템포·박자 변화 편집 UI(TRN-4 이후)
- 드래그로 템포 조정(7.6 「끌어서 조정」): 이 Task는 입력 확정만 한다. 끌기는 마우스 편집과 함께 S3-T6에서 다룬다(이월로 적는다).

## 리스크·결정 요청

- 트랜스포트의 포트 드롭다운이 무엇을 바꾸는지 REQ가 직접 적지 않았다. 7.6의 「출력 포트 선택: 트랜스포트 오른쪽 포트 드롭다운(기본 가상 포트), 트랙 인스펙터의 포트」를 「현재 트랙의 포트를 두 자리에서 다룬다」로 읽었다.
- 16채널이 찬 포트의 새 트랙 채널(1을 씀)은 SEQ-8의 「다른 포트를 권한다」를 메시지로 지키는 세부 판단이다.
