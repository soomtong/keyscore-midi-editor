# 결정 기록: 가상 포트 이름을 바꿀 때 트랙의 포트

- 날짜: 2026-10-19
- 상태: 결정됨(사람, 2026-10-19)
- 관련: REQ OUT-2(포트 이름은 사용자가 정한다), OUT-8(프로젝트에 포트 이름을 저장), S2-T6d

## 상황

트랙은 포트를 이름으로 저장한다(`.ksq`의 `{"named": 이름}`, OUT-8). 앱이 만든 추가 가상 포트도 트랙에서는 이름으로 가리킨다. 사용자가 설정 > MIDI 출력에서 가상 포트 이름을 바꾸면, 옛 이름을 쓰던 트랙을 어떻게 할지 REQ가 정하지 않는다. macOS 쪽에서는 같은 엔드포인트의 이름만 바뀌므로 외부 신디의 연결은 유지된다.

## 선택지

- A: 열린 창마다 옛 이름을 쓰던 트랙을 새 이름으로 고친다(창마다 undo 한 단위). 닫힌 파일은 옛 이름 그대로라, 열면 「포트 없음」으로 보인다.
- B: 프로젝트를 건드리지 않는다. 옛 이름 트랙은 「포트 없음」이 되고 상태줄에 알린다.

## 결정

A(사람, 2026-10-19).
