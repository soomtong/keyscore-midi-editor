# 결정: S2-T6a 재리뷰 한도

- 날짜: 2026-10-18
- 상태: 결정 대기
- 관련: `plan/01-protocol.md` [8], `docs/reports/s2-t6a/review-3.md`, REQ KM-11, KM-12

## 상황

S2-T6a가 재리뷰 3회에 닿았다. 3회차 지적은 하나다.
1. 표준 단축키(`cmd-z`, `cmd-q` 등)를 편집기로 지운 뒤 수식키 교환(KM-11)을 켜거나 끄면 지운 단축키가 다시 동작한다. 편집기는 지울 때의 교환 상태로 파일에 쓰는데, 엔진은 사용자 레이어 전체를 지금의 교환 상태로 다시 교환하고 표준 레이어는 교환하지 않기 때문이다.

제안 둘은 손으로 고친 파일에서만 생기는 근사다.

## 선택지

- A. 지적 1만 고친다: 수식키 교환을 바꿀 때 사용자 파일의 표준 단축키 지정 해제를 새 교환 상태에 맞게 고쳐 쓴다. 그 항목만 보는 좁은 확인 리뷰를 거쳐 병합한다.
- B. 지적 1을 알려진 한계로 두고 S2 출구 수동 확인 항목으로 옮긴 뒤 지금 병합한다.
