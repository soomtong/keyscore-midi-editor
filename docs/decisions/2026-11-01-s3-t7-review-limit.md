# 결정: S3-T7 재리뷰 상한 도달 뒤의 진행

- 날짜: 2026-11-01
- 상태: 결정 대기(추천 A)
- 관련 Task: S3-T7, 관련 문서: `docs/reports/s3-t7/review-3.md`, `docs/reports/s3-t7/report.md`

## 상황

S3-T7 재리뷰가 3회에 닿았다(`plan/01-protocol.md` [8]). 3회차 판정은 「수정 후 재리뷰」이고 차단은 없다. 3회차 지적은 모두 리뷰 2의 카운트 걷기 수정이 만든 것이고, 아래처럼 고쳤다.

- 지적 1(수정): 카운트 걷기가 걸음마다 결과 전체를 훑어 이차 비용이었다(노트 10,000개 debug에서 `9999 n`이 16 s). 첫 걸음만 `step`으로 찾고 나머지는 순번 산술로 바꿨다(`search::walk`, O(n)).
- 제안 2: 노트 없는 트랙 결과에서 끝나는 카운트 걷기의 음높이가 키 반복과 달랐다. 걸은 길에서 마지막으로 지난 노트의 음높이를 쓴다. `walk`가 `step` 반복과 같음을 속성 시험(`walk_equals_repeated_steps`)으로 고정했다.
- 제안 3: 0.05 cent 미만 오프셋이 「+0 cent」로, 음수가 「+」로 보였다. 부호를 지키고 `+<0.1 cent`로 보인다.
- 제안 4: 결정 문서 번호 순서.

리뷰 시험 `review_s3_t7_r3.rs` 9개가 모두 통과한다(리뷰 시험 한 줄의 상수는 clippy `erasing_op` 때문에 같은 뜻의 값으로 바꿨다).

## 선택지

- A(추천). 3회차 수정 범위(`search::walk`, 노트 정보 cent 표시)만 보는 좁은 확인 리뷰 1회. 「병합 가능」이면 병합한다. 이전 Task들(S3-T2, S3-T3c 등)과 같은 길이다.
- B. 리뷰어 재현 시험과 속성 시험이 통과하므로 추가 리뷰 없이 병합한다.
- C. 카운트 걷기를 빼고(카운트 무시를 결정에 적고) 병합한다(범위 재정의).
