## 상황

S3-T3c 재리뷰가 3회에 닿았다(`plan/01-protocol.md`). 3회차 지적은 하나다: 2회차 지적 1의 수정(f4b0b32)이 붙든 키 컨텍스트 경로를 대기 입력보다 오래, Normal 피아노롤 밖에서도 남긴다(수식키 단독 입력이 대기 입력을 비워도 다시 그리지 않음, 메뉴로 뷰·모드가 바뀌어도 붙든 경로로 그림). 고칠 길은 GPUI 공개 API `observe_pending_input`로 대기 입력이 없어지면 붙들기를 놓고, 상태가 키 밖에서 끝나면 그리기에서 곧바로 붙든 경로로 대기 입력을 비우는 것이다.

## 선택지와 결정

- A(결정). 지적 하나를 고치고, 그 수정 범위(붙든 경로를 놓는 때)만 보는 좁은 확인 리뷰 1회. 「병합 가능」이면 병합한다.
- B. 붙들기를 빼고 남는 `i`를 알려진 한계로 두고 병합(범위 재정의).
- C. 고치고 리뷰어 재현 시험이 통과하면 추가 리뷰 없이 병합.
