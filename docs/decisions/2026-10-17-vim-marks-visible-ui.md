# 결정: vim 마크의 눈에 보이는 자리(UI-11)

- 날짜: 2026-10-17
- 상태: 결정됨(YoungTaek)
- 관련: REQ UI-11, 5.8.1(vim 프리셋의 마크 `m a`, `'a`), S2-T4 리뷰 2 지적 4

## 상황

`cursor::SetMark`·`cursor::JumpMark`는 vim 프리셋의 마크다. 인자(마크 글자)가 필요해 팔레트에서는 실행할 수 없는 줄이고, REQ는 화면 자리를 정하지 않았다. UI-11은 모든 기능에 눈에 보이는 자리를 요구한다.

## 선택지

- a. 피아노롤·배치 뷰의 우클릭(컨텍스트) 메뉴에 「마크 설정 ▸ a–z」「마크로 이동 ▸ a–z」를 둔다. 피아노롤을 만드는 S3에서 구현한다.
- b. 메뉴바 편집 > 마크 하위 메뉴(a–z 설정·이동, 52항목).
- c. vim 프리셋 전용 지름길로 보고 UI-11의 예외로 둔다.

## 결정

a(2026-10-17, YoungTaek). 명령 표의 자리는 「피아노롤 우클릭 메뉴」로 적고, 구현은 S3 이월(`plan/stages/13-S3-step-and-pianoroll.md`)이다.
