# 결정 요청: 퀀타이즈·시간 이동·길이 스케일의 규칙

- 관련 REQ: 6.2 EDT-2·EDT-3, 5.10(클립 규칙), 2(녹음 후 자동 퀀타이즈)
- 관련 Task: S0-T7
- 상태: 결정됨 (2026-10-12, 사람)

| 질문 | 결정 |
| --- | --- |
| 퀀타이즈가 맞추는 것 | 시작만 그리드로 옮기고 길이는 유지한다(끝도 함께 움직인다) |
| 그리드 기준점 | 곡의 마디. 노트의 절대 위치가 속한 마디의 시작부터 그리드를 잰다. 마디 중간 박자표 변화도 반영된다 |
| 결과 노트가 클립 밖으로 나갈 때 | 끝을 넘으면 클립을 마디 단위로 늘린다. 늘린 클립이 다음 클립과 겹치면 연산 전체를 거부한다. 클립 시작 앞으로 나가면 연산 전체를 거부한다 |
| 길이 스케일 | 선택의 가장 이른 시작을 기준으로 노트 시작 간격과 길이를 함께 비율만큼 늘이고 줄인다(배속·반속) |
