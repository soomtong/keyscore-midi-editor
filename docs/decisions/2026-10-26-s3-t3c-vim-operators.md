# 결정: S3-T3c vim 오퍼레이터·텍스트 객체·비주얼 선택·카운트의 세부

- 날짜: 2026-10-26
- 상태: 결정됨(YoungTaek, 2026-10-26, 네 항목 모두 추천안)
- 관련 REQ: 5.8.1(`d` `y` `c` 오퍼레이터, `dw` `dac` `yib` `vin`, `v` `V` `Ctrl+v`, `e` `E` `w` `b` `W` `B` `f` `F` `;` `,` `g g` `G`, 숫자 카운트 접두), 5.7(vim 카운트 `3l`), KM-5, P8

## 상황

REQ 5.8.1은 오퍼레이터·텍스트 객체·비주얼 모드를 예시(`dw` `dac` `yib` `vin`)와 한 줄 설명으로만 준다. 구현하려면 다음이 필요하다.

1. 오퍼레이터 + 모션이 작용하는 노트 범위.
2. 텍스트 객체 `i n` `i b` `a c`의 대상.
3. `v` `V` `Ctrl+v`의 선택 규칙과 선택이 있을 때 오퍼레이터의 동작.
4. 카운트(`3 l`, `d 3 w`)와 `.` 반복의 범위.

## 선택지와 결정

1. 모션 범위
   - A(결정). 읽기 순서: 노트를 (절대 시작 틱, 음높이) 순으로 늘어놓은 글처럼 다룬다. 커서 칸부터 모션 목적지 칸까지의 노트가 대상이다. `h` `l` `w` `b` `W` `B` `{` `}` `Ctrl+h` `Ctrl+l`은 목적지를 빼고(vim exclusive), `e` `E` `f` `F` `;` `,`는 목적지를 넣는다(inclusive). 화음은 음높이 순으로 한 노트씩이다. `j` `k`(음높이 모션)는 오퍼레이터와 결합하지 않고 대기를 취소한다.
   - B. 시간 범위의 모든 음높이.
   - C. 커서 음높이 행만.
2. 텍스트 객체
   - A(결정). 노트만: `i n` = 커서 노트, `i b` = 커서 마디에 걸친 현재 클립 노트(`g b`와 같은 집합), `a c` = 현재 클립의 노트 전부(`g B`와 같은 집합). `d a c`도 노트만 지우고 클립 블록은 남긴다. `y`는 이 노트를 클립보드로 복사한다.
   - B. `a c`는 클립 블록까지(`d a c`가 클립을 지움).
3. 비주얼 선택
   - A(결정). vim 대응: `v` = 기준 칸과 커서 칸 사이 읽기 순서의 노트(양끝 포함, vim charwise), `V` = 기준 칸과 커서 칸의 시간 범위에 걸친 모든 음높이의 노트(linewise), `Ctrl+v` = 음높이 × 시간 직사각형(기본 프리셋 `Shift` 넓히기와 같은 규칙). 이동 키가 선택을 넓히고, 같은 키를 다시 누르거나 `Esc`면 해제한다. 선택이 있을 때 `d` `y` `c`는 모션을 기다리지 않고 선택에 바로 작용한다(`g b`로 고른 선택도 같다). 상태줄에 VISUAL / V-LINE / V-BLOCK을 표시한다.
   - B. 세 키 모두 기준 칸만 찍고 직사각형을 넓힌다. 상태줄 표시 없음. `d` `y` `c`는 선택이 있어도 모션을 기다린다.
4. 카운트와 `.`
   - A(결정). 모션 카운트 포함: `3 l`, `3 w` 같은 이동 카운트도 이 Task에서 동작한다. 오퍼레이터의 카운트는 곱한다(`3 d 2 w` = 6). `.`은 `d` `c`를 같은 모션·객체·카운트로 지금 커서에서 다시 한다(`c`는 삭제 뒤 Step 진입까지). `y`는 편집이 아니라 `.`의 대상이 아니다.
   - B. 카운트는 오퍼레이터와 결합할 때만, 이동 카운트는 다른 Task.

## 후속

- 결정에 없는 작은 규칙(겹친 오퍼레이터 `d d`, 대기 중 다른 키, 오퍼레이터 뒤 Step 진입 자리 등)은 계획 「끝의 정의」에 글로 먼저 적는다.
